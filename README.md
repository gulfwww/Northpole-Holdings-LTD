### About

Established in **2014**, North Pole Holdings Limited is an international consultancy delivering sourcing, procurement, project development, and advisory services throughout Africa, the Middle East, and Europe.

The company supports projects from early feasibility studies through execution while providing structured commercial and operational guidance.

## Getting Started

### Install dependencies

```bash
npm install
```

### Run development server

```bash
npm run dev
```

Open:

```
http://localhost:3000
```

---

## Production

Build the project

```bash
npm run build
```

Start production server

```bash
npm run start
```
